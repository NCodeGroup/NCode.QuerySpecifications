# Deprecated

> **This library is retired.** It was never finished and has not changed since 2020, and nothing in .NET replaces it directly.
>
> - It is an unfinished alpha: the README was never written (it says "TODO"), and only two pre-release versions were published (`0.0.1-alpha` and `0.0.2-alpha`), for .NET Standard 2.0 and .NET Core 3.1.
> - It implemented the specification pattern, with query specifications and an Entity Framework Core builder. If you need that, a maintained library such as [Ardalis.Specification](https://github.com/ardalis/Specification) covers it.
>
> The NuGet package `NCode.QuerySpecifications` is deprecated and this repository is archived. The code stays available as it is.
